# 架构

## 一句话

大脑留在 Linux 沙箱，手按需伸到 Windows；Windows 不开任何入站端口；
删除能力在工具集里根本不存在，只有"申请删除 → 人确认 → 回收站"。

## 拓扑

```
┌──────────── Windows 11（手）────────────┐      ┌──── Linux / PVE（脑）────┐
│                                         │      │                          │
│  Windows-MCP   127.0.0.1:18080          │      │  DSH + mcp-client        │
│       ▲                                 │      │       │                  │
│       │                                 │      │       │ streamable-http  │
│  确认代理      127.0.0.1:18081  ◀───────┼──────┼───────┘                  │
│       ▲                                 │ ssh  │                          │
│       └── ssh -R 18081:127.0.0.1:18081  │ -R   │  模型 key / 密钥 / 审计  │
│                                         │      │                          │
│  不开任何入站端口                         │      │  工作区 /root/lab        │
└─────────────────────────────────────────┘      └──────────────────────────┘
```

- Windows 主动出站连 Linux，用 `-R` 把代理端口发布到 Linux 的 `127.0.0.1`
- 局域网扫不到 Windows 上任何新端口
- 隧道账号受限：`restrict,port-forwarding,permitlisten="127.0.0.1:18081"`

## 威胁模型

| 威胁 | 处置 |
|---|---|
| 提示注入让 agent 删库 | 工具集无删除能力；唯一入口需人确认；冻结键鼠 |
| agent 自己点确认框 | 待确认期间拒绝一切输入类工具；explorer / 浏览器对其不可见 |
| agent 拿到 shell 为所欲为 | `Shell` / `PowerShell` 工具从列表移除；App 启动改白名单 |
| 局域网设备连进来 | Windows 零监听；隧道只走内网 |
| tailnet 里其它设备 | 用户明确要求保留现有访问，不动 |
| Windows 凭据泄露 | agent 只能看到白名单目录，碰不到 DPAPI / cookie / SSH key |
| 改坏了回不来 | `kill` 隧道即断开；工具集回滚无需重装 |

## 删除协议

```
agent ──fs_trash(paths, reason)──▶ 代理
   1  校验：在白名单根内 / 非网络盘 / 理由 ≥15 字 / ≤50 项
   2  冻结输入（Click / Type / Shortcut / App 一律拒绝）
   3  比对回收站配额（超限会被 Windows 永久删除，必须提前拦）
   4  原生置顶弹窗：理由 + 文件清单 + 大小 + 时间 + "会进回收站"
   5  人点「移进回收站」→ SHFileOperation(FOF_ALLOWUNDO)
   6  审计 JSONL：时间 / 理由 / 路径 / 大小 / 结果
   7  返回："已进回收站 N 项，清空需你本人操作"
```

**没有 `empty_recycle_bin` 工具。** 这条能力永不提供。

## 决策

- **删除只做一道锁**：程序里没有删除功能。双账户 + NTFS 拒绝删除是内核级保证，代价是多花半天。
- **不碰 tailnet 现有暴露**：用户明确要用 445/3389/902 从 iPhone 访问。只保证新组件绑 `127.0.0.1`。
- **文件层 SMB3 加密**，不引入 OpenList。
- **USB 不做直通**：U 盘走共享、手机走 adb、串口转 TCP、摄像头走 RTSP。
